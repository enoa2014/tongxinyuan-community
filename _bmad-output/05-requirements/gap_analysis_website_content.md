# 官网内容系统：以有架构与新需求差异分析 (Gap Analysis)

本文档将您提出的“信息披露、暖心故事、活动发布”新需求与系统现有架构进行对比，并提出融合方案。

## 1. 总体评估 (Executive Summary)

*   **结论**: 现有架构（Next.js + Tailwind + PocketBase）**完全可以支撑**新需求，无需重构核心，只需进行**增量开发**。
*   **主要差异**:
    1.  **视觉风格**: 现有网站以“品牌绿/医疗蓝”为主，新需求的“捐赠公示”偏向“红/金”传统风格。需要做风格隔离或融合。
    2.  **缺失板块**: 目前只有 `news` (新闻) 和 `services` (服务)，缺少专门的 `transparency` (透明公示) 和 `activities` (活动报名) 前台页面。

## 2. 差异详情与解决方案

### A. 信息披露 (Information Disclosure) -> [GAP]
*   **现状**: 只有 `donate` (捐赠引导) 页面，无数据公示。
*   **需求**: 季度财报、大额捐赠公示（长图风格）、运营数据。
*   **解决方案**:
    *   **新增页面**: `/transparency` (透明公益)。
    *   **样式处理**: 
        *   **数据看板**: 保持网站整体的现代简约风格（Green/White），使用图表展示。
        *   **捐赠公示**: 在网页上以“缩略卡片”形式展示，点击后弹窗显示完整的“红/金”长图（复用生成器的样式）。这样既保留了传统庆典感，又不破坏网站整体的清爽感。

### B. 暖心故事 (Stories) -> [PARTIAL FIT]
*   **现状**: 已有 `/news` 模块。
*   **需求**: 分类（官方、投稿、媒体）、关联项目。
*   **解决方案**:
    *   **复用并升级**: 将 `/news` 升级为 `/stories` (或保留路径仅改UI)。
    *   **功能增强**: 增加“标签筛选”功能（#志愿者 #治愈故事）。
    *   **投稿入口**: 在页面底部增加“我要投稿”按钮，链接到简单的表单或邮箱指引。

### C. 活动发布 (Activities) -> [GAP]
*   **现状**: 无专门活动列表页。
*   **需求**: 公开课、长期项目、报名功能（扫码/表单）。
*   **解决方案**:
    *   **新增页面**: `/activities` (活动中心)。
    *   **功能**: 
        *   列表页显示“报名中/已结束”状态标签。
        *   详情页根据 `registration_type` 显示“扫码入群”或“填写报名表”。

## 3. 实施路线图 (Implementation Roadmap)

### Phase 1: CMS 后台增强 (已在 Phase 8.3 计划中)
*   **目标**: 让工作人员能录入这些数据。
*   **核心**: 捐赠海报生成器、活动发布表单、文章分类管理。

### Phase 2: 官网前台页面开发 (New Phase 8.4)
*   **新增**: `TransparancyPage` (透明公示页)。
*   **新增**: `ActivitiesPage` (活动列表页)。
*   **优化**: `StoriesPage` (故事列表页，改版样式)。

## 4. 视觉风格建议 (Visual Strategy)

建议采用“**容器现代，内容传统**”的策略：
*   **网站框架**（导航、页脚、背景）：保持 **Brand Green (#16A34A)**，传达专业、洁净、医疗关怀的感觉。
*   **特定内容**（捐赠证书/喜报）：允许使用 **Festival Red (#B22222)** 和 **Gold (#FFD700)**，作为“内容图片”或“强调卡片”嵌入在页面中。

**结论**: 无需推翻现有设计，按“板块”进行增量添加即可。

## 1. Version Control & Dependencies
- **Strict Version Alignment**: When performing coding development or adding new dependencies, **ALWAYS** use the `context7` MCP tool to check for the correct, compatible versions and best practices. Do not guess versions.

- **Backend**: PocketBase (v0.22+).
- **Styling**: TailwindCSS.
